## Summary
A simple noise-based brick wall generator programmed in Grasshopper, inspired by an example from a Reddit thread. 
The pattern combines smooth value noise, random noise, and a Graph Mapper to control the distribution and transition between active and inactive bricks.

## Reference / Source
- Project: Little Shelter Hotel
- Architect: Department of Architecture
- Location: Chiang Mai, Thailand
